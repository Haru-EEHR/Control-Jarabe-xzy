# Control Fisicoquímico - Estándar de Jarabe Terminado

Aplicación web desarrollada para la consulta de especificaciones fisicoquímicas, evaluación en tiempo real de muestras de laboratorio, bitácora acumulada con fecha/hora y exportación a Excel.

## Archivos Incluidos
- `index.html`: Estructura principal de la aplicación web.
- `styles.css`: Hoja de estilos en tema oscuro (Carbón y Ámbar) con indicadores visuales en verde (`CONFORME`) y rojo (`FUERA DE ESPECIFICACIÓN`).
- `app.js`: Lógica de búsqueda rápida, evaluación automática, bitácora histórica con fecha/hora y exportación CSV para Excel.
- `database.json`: Base de datos completa con los 34 productos transcritos exactamente del estándar.

## Cómo Publicar en GitHub Pages (Para usar desde PC, Tablet o Celular)
1. Ingresa a [GitHub](https://github.com/) y crea un nuevo repositorio público (por ejemplo: `control-jarabes-lab`).
2. Haz clic en **Add file > Upload files** y sube los archivos `index.html`, `styles.css`, `app.js`, `database.json` y `README.md`.
3. Haz clic en **Commit changes**.
4. Ve a **Settings** (Configuración) > **Pages** (en el menú izquierdo).
5. En **Branch**, selecciona `main` y haz clic en **Save**.
6. En 1 o 2 minutos aparecerá el enlace web en la parte superior. Ábrelo desde tu computadora o celular (en el celular puedes usar la opción *"Agregar a la pantalla de inicio"* para usarlo como una app).
